# Code Review

全面的代码审查 Skill：分析 git diff，大改动（500+ 行）按模块分批审查，扫描代码质量、安全漏洞、最佳实践合规性。问题按 P0-P3 优先级分类，支持交互式修复。兼容前端和后端代码。

## 安装

```bash
npx skills add lenslp/skills --path code-review
```

## 检查项

| 类别 | 检查内容 |
|------|---------|
| **代码质量** | 正确性、可读性、类型安全、API 设计 |
| **安全** | 注入攻击、认证授权、数据泄露、输入验证、依赖 CVE、前端安全 |
| **最佳实践** | 架构、错误处理、测试、性能 |
| **前端** | 组件设计、渲染性能、状态管理、可访问性、包体积、UX 健壮性 |

## 优先级

| 优先级 | 定义 | 处理方式 |
|--------|------|---------|
| **P0** | 安全漏洞、数据丢失、崩溃 | 必须立即修复 |
| **P1** | 逻辑错误、缺少错误处理、契约破坏 | 合并前修复 |
| **P2** | 代码质量、可读性、测试覆盖不足 | 应该修复 |
| **P3** | 风格规范、命名、小优化 | 可选改进 |

## 在 Cursor 中使用

安装后 skill 会自动注册，在 Cursor Chat（Agent 模式）中直接使用。

### 自动触发

当提问包含以下关键词时自动激活：

- "帮我 review"
- "review my code"
- "检查代码质量"
- "安全扫描"

### 手动触发

示例提问：

```
帮我 review 一下最近的代码改动
```

```
对比 main 分支，review 当前分支的变更
```

```
检查一下我 staged 的代码有没有安全问题
```

### Review 完成后

报告按 P0-P3 优先级列出所有问题，然后选择修复方式：

- 按优先级：`fix P0`、`fix P0 and P1`
- 按模块：`fix src/auth/`
- 按编号：`fix #1, #3, #5`
- 全部修复：`fix all`
- 跳过：`skip`
